4 · Rules for every session

  • Commit and credit as Kragnoth, never his real name.
  • Art: Excalibur first, Immersive Engineering as loan styling, Create palette discipline. Never commit the Excalibur pack; credit Maffhew.
  • Never commit third-party material: Create's assets (All Rights Reserved), Mojang/decompiled code, IE or IP code and manual text, or any jars. Commit scripts that fetch them.
  • Models reference create: textures. New art uses Create's exact ramps.
  • Commands for Kragnoth's PC use fish syntax (CachyOS, Prism Launcher, RX 570 with 4 GB).
  • No client or server launches unless he asks for a full compile and load-up.
  • "Can you do X?" means a brief feasibility answer. Simple asks mean just deliver.
  • Every change is a release: bump the version, update dev/SAVE_FORMAT.md and dev/TODO.md, and hand Kragnoth a source zip (no build/, .gradle/, run/, .git/).
